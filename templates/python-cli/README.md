# Python CLI Template

A tiny Python project structure with a function, command-line entry point, and unit tests. No third-party dependencies are required.

## Requirements

Python 3.10 or newer is recommended.

## Run

From this directory:

```bash
python main.py
```

## Test

```bash
python -m unittest discover -s tests -v
```

Use this as a base for a small automation, command-line helper, or problem-solving prototype. Document installation steps if your project adds dependencies.
