# Web App Template

A minimal, dependency-free browser prototype. Start by opening `index.html` locally, or serve this folder using your preferred static web server.

## Included

- `index.html`: semantic page structure.
- `styles.css`: responsive baseline styles and readable focus states.
- `app.js`: small interactive example.

## Customize

Replace the sample idea, make the main user journey usable from the keyboard, test narrow screens, and document limitations. Do not put private API keys in browser JavaScript; browser code is public to users.
