# Code of Conduct

We welcome contributions that make hackathons more useful, fair, accessible, and respectful. Participants, mentors, judges, organizers, and contributors are expected to treat others with respect, avoid harassment and discrimination, protect personal information, credit others' work, and follow event rules.

If you experience or observe harmful conduct, report it privately to the event's designated contact. Organizers must fill in that contact before using this kit. Do not publish sensitive details in public issues. Organizers should handle reports promptly, fairly, and as confidentially as practical.
